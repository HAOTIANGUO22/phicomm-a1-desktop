## 状态保留修复

旧版在 A1 重新建立 TCP 连接时会清空已收到的开关和风速。A1 在状态未改变时不一定再次上报，因此会出现“已连接，但没有工作状态和数字，改档后才恢复”的现象。

从未取得有效设备回报时，中间显示大号 `--`。收到状态后，安静运行不会让显示过期。重连、断网或 ESP32 重启后仍保留最后回报的风速，底部标注“上次开机／上次关机”，上方继续显示真实连接状态；新上报到达后恢复普通状态。网页也会标注“上次上报”。

最后一次回报按 A1 的 MAC 保存在 NVS，只在开关或风速实际发生变化时写入，切换到另一台 A1 不会沿用旧设备状态。下发指令不会直接覆盖这些数值，等待确认期间仍显示设备的最后回报。

## 验证

`3.1.1-dev` 已在一台原厂 A1 上验证：真实开机回报风速 44 后重启 ESP32，在 A1 未重新上报的情况下恢复记录；随后静置 92 秒、没有收到新状态回报，数值仍然保留。最后收到关机回报后更新为关机，恢复测试前状态。状态模型的原生 C++ 回归测试覆盖重连、部分回报、重启恢复及不同 MAC 的缓存隔离。

测试源码位于 `tests/firmware/test_oled_model.cpp` 和 `tests/firmware/test_report_state.cpp`，两项原生 C++ 断言测试均通过；网页 JavaScript 语法检查、ESP32 固件编译和烧录校验也通过。本次编译使用 ESP32 Arduino Core 3.3.11、IRremote 4.7.1、ArduinoJson 7.4.3、ESP_SSLClient 3.1.3、U8g2 2.36.19。

## 升级与隐私

升级沿用 `firmware/a1_oled` 目录及原来的本机 `config.h`，使用相同板型和默认分区，关闭整片擦除，保留 NVS 中的网络配置与红外学习记录。该固件和本机配置可能带有个人密码、证书或设备地址，不应随源码上传。

从发行页下载通用源码。已有本机 `config.h` 时，保留它并进行普通编译；新安装按接线指南使用 `build.ps1 -Unconfigured`，在自己的电脑上生成密码和证书后再编译烧录。公开仓库不包含个人 `config.h`、生成的网页头、已配置的 BIN、Flash／NVS 备份、私钥、网络记录或运行日志。
