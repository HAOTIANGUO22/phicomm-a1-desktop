# Windows 控制台 EXE 使用指南

适用于原厂斐讯悟净 A1 `v1.47`、Windows 10／11 x64。无需安装 Python。其他固件尚未验证。

## 下载与配网

在 [v0.2.0 发行页](https://github.com/HAOTIANGUO22/phicomm-a1-desktop/releases/tag/v0.2.0)下载完整便携 ZIP，解压到自己有写入权限的目录。也可以单独下载控制台 EXE。

尚未联网的 A1，先运行 `A1Provisioner-Windows-x64.exe`，选择家庭 2.4 GHz Wi-Fi，按提示按住机身 Wi-Fi 键约 1–2 秒，等待身份验证成功。记录结果中的 **IP 和完整 MAC**。已联网时，可直接使用配网工具的“只查找已联网的 A1”，或从路由器客户端列表取得这些信息。

配网过程详见 [Windows 配网指南](windows-wifi.md)。配网成功意味着 A1 已连接家庭 Wi-Fi，之后还需要完成下面的控制台接入。

## 首次启动控制台

双击 `A1Controller-Windows-x64.exe`。首次启动显示空白的连接参数，不会自动使用构建者的设备信息。

| 字段 | 填写方法 |
| --- | --- |
| 净化器 IP、MAC | 配网工具验证结果或路由器客户端列表；MAC 必须完整 |
| 电脑 IP | 填写净化器 IP 后，点“按净化器地址确定本机 IP”；也可填写同一局域网的固定电脑地址 |
| 路由器 IP | 当前家庭网络的默认网关 |
| 子网掩码 | 使用本机实际掩码；默认值为 `255.255.255.0` |
| 上游 DNS | 可留空，留空使用路由器地址 |

填写自己的地址后保存。电脑、A1、路由器必须在同一子网，且地址互不相同。运行控制台时需要保留电脑网络连接；电脑同时接网线时，可使用稳定的有线地址控制。

Windows 如出现防火墙联网提示，请由使用者允许控制台接受所在家庭局域网的连接。软件使用 UDP `53`、TCP `9000` 和 TCP `443`；已有相同服务或重复运行控制台会导致启动失败。

## 连接到这台电脑

1. 打开控制台 **连接设置 → 连接到这台电脑**。
2. 程序核对原厂型号／固件身份及 MAC 后，将这一台 A1 设为填写的静态 IP，并把它的 DNS 指向电脑。不会修改路由器的全局 DNS，也不会刷写固件。
3. 等待约半分钟重新联网。首次使用若尚未收到状态，请给 A1 断电再通电一次，等待它主动连接和上报。
4. 控制台收到设备连接及状态后，可开关、调速和切换模式。

建议先在路由器中为电脑和 A1 保留固定地址，防止地址变动或静态 IP 与其他设备冲突。电脑地址改变时，需要更新控制台参数及设备的连接目标。

## 控制、恢复与本机数据

- 开启净化：进入日常模式，同时下发记忆风速。
- 关闭：下发关机动作。
- 手动风速：`30–85`；睡眠 `30`、强劲 `85`，日常恢复上次手动设定。
- 数字是设备风速设定值，不能当作风量百分比或实测转速。界面以设备回报确认变化。
- 控制期间保留软件运行。若不再使用本机控制，先点击 **连接设置 → 恢复自动联网**，再退出；此操作保留家庭 Wi-Fi 凭据并恢复 DHCP。

首次运行会在 EXE 旁创建 `data/`，保存本机连接设置、历史状态、连接记录及当场生成的本地证书。这些文件可能含使用者的设备标识，应只留在自己的电脑。分享时使用 GitHub 发行附件，不要复制自己的 `data/`。

发行附件经过源码、压缩资源和 Python 字节码检查，不包含构建者的家庭 Wi-Fi、个人 IP／MAC、用户目录、历史协议头、私钥或运行日志。校验值见发行页中的 `SHA256SUMS.txt`。
