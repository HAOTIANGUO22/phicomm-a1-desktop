# A1 3.2 OLED 固件源码

这是 ESP32 独立版的 OLED 固件。上方显示连接状态，中间用大号数字显示风速，底部用小字显示开关或等待状态。手机网页与实体红外遥控保留，运行时无需电脑或 Python。

`3.2.0-dev` 默认在开机或最后一次操作 30 秒后关闭 OLED 发光。按已绑定的遥控器按键或在网页上操作会唤醒屏幕，网页也有单独的「唤醒屏幕」按钮。熄屏期间 A1 仍保持联网，后台状态查询和设备回报不会点亮屏幕。可在 `oled_settings.h` 修改 `OLED_IDLE_TIMEOUT_MS` 后重新编译。若开发板的电源指示灯直接接在供电线上，它会随供电常亮。

**3.1 显示布局：[变更和升级说明](../../docs/oled-3.1.md)。**

`3.1.1-dev` 修复重连后状态消失：保留最后一次真实回报，控制器重启后也可恢复。尚未重新确认的内容标注“上次开机／上次关机”，新回报会自动替换；首次使用、从未收到回报时仍显示 `--`。

**从这里开始：[3.0 接线、编译、配网与验收教程](../../docs/oled-3.0.md)。**

- 主程序：`a1_oled.ino`；OLED 引脚、地址和驱动选择：`oled_settings.h`。
- OLED 默认按 SSD1306 适配，SDA → GPIO21，SCL → GPIO22，VCC → 3V3，GND → GND；红外接收仍用 GPIO27。驱动型号待实物确认。
- `build.ps1 -Unconfigured` 会生成首次配网所需的本机配置与内嵌网页，并编译固件。先按教程安装库和板卡支持；保留脚本生成的网页登录密码。
- 2.0 升级用户可用 `-PrepareOnly -ConfigFrom ..\a1_standalone\config.h` 沿用本机密码与证书，再普通编译。网络和已学红外键保存在原 NVS 命名空间。
- `config.h`、`web_page.h` 和编译产物不提交到 GitHub。公开源码不带个人 Wi-Fi、设备地址、网页登录密码或证书私钥。

本目录独立于 [2.0 源码](../a1_standalone/)。2026-11-09 已在一块经典 ESP32 和 I²C 0x3C OLED 上烧录 3.0，用户确认中文及方向正常；3.1 已完成编译、烧录、版本回报和 A1 重连检查，原网络及 7 个红外按键保留。机械修订 2 的新盖子也已由用户确认可安装。其他屏幕及控制芯片仍需按实际模块验证。
