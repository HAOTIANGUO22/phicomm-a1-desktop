# A1 3.0 OLED 固件源码

这是在 ESP32 独立版上增加 OLED 的 3.0 预览版。屏幕显示连接、开关和风速，手机网页与实体红外遥控保留。运行时无需电脑或 Python，电脑用于首次编译和烧录。

**从这里开始：[3.0 接线、编译、配网与验收教程](../../docs/oled-3.0.md)。**

- 主程序：`a1_oled.ino`；OLED 引脚、地址和驱动选择：`oled_settings.h`。
- OLED 默认按 SSD1306 适配，SDA → GPIO21，SCL → GPIO22，VCC → 3V3，GND → GND；红外接收仍用 GPIO27。驱动型号待实物确认。
- `build.ps1 -Unconfigured` 会生成首次配网所需的本机配置与内嵌网页，并编译固件。先按教程安装库和板卡支持；保留脚本生成的网页登录密码。
- 2.0 升级用户可用 `-PrepareOnly -ConfigFrom ..\a1_standalone\config.h` 沿用本机密码与证书，再普通编译。网络和已学红外键保存在原 NVS 命名空间。
- `config.h`、`web_page.h` 和编译产物不提交到 GitHub。公开源码不带个人 Wi-Fi、设备地址、网页登录密码或证书私钥。

本目录独立于 [2.0 源码](../a1_standalone/)，不替换旧版本。固件在 2026-11-07 完成编译及离线状态检查，OLED 实显和 A1 联机仍待实测；机械修订 2 的新盖子已于 2026-11-09 由用户确认可安装。
